# Installed structure fixtures

These deposited mmCIF subsets retain the first-model atom rows for selected chains, native author residue numbering, full deposited sequences and entity descriptions. They are portable scientific test inputs, not package-specific prepared archives.

8IXA and 8IXB exercise different chain labels, missing residues and multi-chain correspondence. 7NJP provides a different protein family. The package contains no rules specific to these proteins. Tests require neither the original investigation folders nor a network connection.
